# 🌟 About Me 🌟

👨‍💻 Software Engineer | Java Spring Boot | Python | Data Engineering | AI Solutions

Hi there! I'm Achraf NEJJARI, a Software Engineer with a versatile background 
in full-stack development, data engineering and AI-powered solutions. My work 
is defined by the ability to build robust backend systems, engineer scalable 
data pipelines and integrate intelligent AI features into production applications.

## 💡 Technical Expertise

✔ **Backend Development:** Proficient in Java Spring Boot and Python, designing 
secured REST APIs with microservices architecture, TLS/SSL security and 
optimized relational database schemas (PostgreSQL, MySQL)

✔ **Data Engineering:** Experience in ETL/ELT pipelines, Apache Kafka streaming, 
Apache Spark transformations and AWS S3 storage, enabling reliable data 
processing and real-time analytics at scale

✔ **DevOps & Deployment:** Expertise in Docker, GitHub Actions CI/CD pipelines 
and cloud infrastructure on AWS, automating deployments and ensuring 
production-grade reliability

✔ **AI & NLP:** Hands-on experience fine-tuning GPT-2 with HuggingFace 
Transformers, building LangChain chatbots and applying Prompt Engineering 
in real production environments

## 🔍 Professional Highlights

➤ Developed Kafka smart producers in Python to automatically simulate and test 
financial transaction flows by card scheme (CB, Mastercard, Visa) at Effyis Group

➤ Contributed to building a full-stack e-commerce platform with Java Spring Boot 
microservices and React for a French company (Remote Freelance)

➤ Designed a Smart City web application for green space management with 
automated PDF reporting and role-based access control

➤ Built a real-time weather data pipeline with Kafka, Spark, PostgreSQL 
and Streamlit, fully containerized with Docker and automated via GitHub Actions

➤ Fine-tuned GPT-2 on HR-specific datasets and integrated an intelligent 
NLP chatbot into a full-stack HR management platform (TeamCore)

## 🎯 Delivering Impact Through Innovation

My expertise bridges backend engineering and data solutions, enabling me to 
deliver scalable, production-ready systems. Committed to writing clean code,

to solve real-world business problems.
